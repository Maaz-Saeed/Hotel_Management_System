# Assignment 02 – UI-Based Spam Email Detection

## Files
- `email.csv` — the dataset provided for the assignment.
- `Assignment_02_Spam_Email_Detection.ipynb` — complete Jupyter Notebook.
- `spam_email_detector.py` — full working Tkinter interface.
- `requirements.txt` — required packages.

## Run the Notebook
Open the `.ipynb` file in Jupyter Notebook, JupyterLab, VS Code, or Google Colab and run the cells in order.

## Run the GUI
Keep `email.csv` and `spam_email_detector.py` in the same folder, then:

```bash
pip install -r requirements.txt
python spam_email_detector.py
```

The GUI supports:
- Entering a custom email
- Spam example button
- Not Spam example button
- Predict button
- Confidence percentage
- Clear button

## Dataset
The application uses the uploaded `email.csv` dataset rather than the sample dataset from the earlier version.
